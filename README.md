# Kids Online Safety Guide — Age-Based Checklists, Platform Controls & Conversation Starters for Parents

"Keep them safe online" is easy to say and hard to do — the right rules for a 6-year-old are wrong for a 16-year-old. This free guide gives parents **age-based safety checklists** for five bands (**0–5, 6–9, 10–12, 13–15, 16–18**), the **platform controls** actually worth turning on (YouTube Kids, TikTok Family Pairing, Roblox account restrictions, Family Link / Screen Time), and **conversation starters** engineered not to start a war. Create a **private profile per child — first name and age only** — and track each child's checklist as they grow.

**Live Demo:** https://anaskhan0009.github.io/kids-online-safety-guide/

## Features

- **5 age-band checklists (27 items)** that evolve with the child — from co-watching and autoplay-off at 0–5, through game-chat rules at 6–9, first private accounts at 10–12, the sextortion talk at 13–15, to full security handover at 16–18
- **Per-child profiles with full CRUD** — create / view / edit / delete a profile for each child; each profile stores its own checklist progress and your notes; changing age moves the child to the right band automatically
- **Platform controls cheat-sheet** — the specific switches that matter in YouTube, TikTok, Roblox, WhatsApp and at device level (Family Link / Screen Time, app-install approval)
- **Conversation starters** — five tested openings, including the one promise ("tell me and we'll fix it together — you won't be in trouble") that makes children actually report grooming and bullying
- **Privacy-respecting by design** — profiles ask for first name + age only, live solely in your browser account, and export/import as JSON
- **Free local account system** — sign up / log in (salted SHA-256 hashed passwords, browser-only) or browse the whole guide as a guest

## How to Use

1. Open the [live demo](https://anaskhan0009.github.io/kids-online-safety-guide/) (or `index.html` locally).
2. Read the platform-controls and conversation sections — they need no account.
3. Log in, create a profile per child (first name + age), and open their age-band checklist.
4. Work through items together where age-appropriate; tick what's genuinely in place. Revisit at every birthday — the band changes, and so should the rules.

## Why Age-Based?

A single rulebook fails twice: too lax for a preschooler with a tablet, too insulting for a 17-year-old with a job. Age-banded guidance lets supervision *graduate* — heavy control early, coached independence in the middle, and a planned handover of passwords, privacy settings and judgment by the late teens. The goal was never permanent monitoring; it's an adult who doesn't need it.

## Ethical Use

This is a **defensive parenting-education tool**. It encourages supervision that is agreed, transparent and age-appropriate — and stores the minimum data (first name + age) needed to track your own family's progress.

## Tech

Single self-contained `index.html` — HTML, CSS, vanilla JavaScript, WebCrypto (SHA-256 password hashing), localStorage persistence.
